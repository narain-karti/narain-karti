<h3>🚀 Featured Engineering</h3>
</div>

<h4>📦 <a href="https://github.com/narain-karti/DATADOC">DATADOC</a> — The Open-Source OS for Dataset Engineering</h4>
<p>
<i>Leakage-safe tabular dataset preparation · Python · Polars · Apache Arrow · MIT · 16★</i>
</p>
<p>
<a href="https://pypi.org/project/datadoc-cli/"><img src="https://img.shields.io/pypi/v/datadoc-cli?style=flat-square&color=f59e0b" alt="PyPI" /></a>
<a href="https://narain-karti.github.io/DATADOC/"><img src="https://img.shields.io/badge/docs-GitHub_Pages-f59e0b?style=flat-square" alt="Docs" /></a>
<a href="https://github.com/narain-karti/DATADOC"><img src="https://img.shields.io/github/stars/narain-karti/DATADOC?style=flat-square&color=f59e0b&label=stars" alt="Stars" /></a>
</p>
<ul>
<li>Enforces <b>strict train-only fitting</b> for imputation, encoding, and scaling — every learned parameter is frozen into a serializable <code>pipeline.json</code> to eliminate distribution bleed.</li>
<li><b>Sub-second profiling on millions of rows</b> via vectorized Polars/Arrow execution, with human-readable transformation plans and provenance manifests.</li>
<li>Ships a <b>9-plugin transformation ladder</b>, an interactive web studio, HTML audit reports, and advisory AI feature hypotheses (multi-provider via LiteLLM).</li>
</ul>

<hr/>

<h4>🚦 <a href="https://github.com/narain-karti/Project-K">Project K</a> — AI-Driven Hybrid Edge-Cloud Traffic Intelligence</h4>
<p>
<i>Turns passive CCTV into real-time smart traffic nodes · YOLOv8 · NVIDIA Jetson · SUMO · MQTT</i>
</p>
<ul>
<li>Real-time vehicle perception on <b>NVIDIA Jetson Orin at &lt;120 ms latency</b>, detecting incidents in under 2 seconds.</li>
<li>Multi-agent <b>reinforcement learning for adaptive signal phases</b> (SUMO) and MQTT-based emergency corridor green-wave preemption.</li>
<li>🏆 Won <b>National Runner-Up at the OpenAI Academy × NxtWave GenAI Buildathon (₹3,00,000 prize)</b>.</li>
</ul>

<hr/>

<h4>🧠 <a href="https://github.com/narain-karti/Quorum">Quorum</a> — Multi-Agent "Board of Directors"</h4>
<p>
<i>Stress-test decisions against AI personas · React · Fastify · ReactFlow · SQLite</i>
</p>
<ul>
<li>Simulates boardroom debates with <b>CMO, CFO, CTO, COO &amp; Contrarian personas</b> over a single query, streamed as a live debate graph.</li>
<li>Local-first persistence with SQLite full-text knowledge-base chunking; structured JSON agent outputs via OpenRouter.</li>
<li>🏆 <b>Top Rank at the TakeOver'26 National Hackathon.</b></li>
</ul>

<hr/>

<h4>🎥 <a href="https://github.com/narain-karti/DECEPTRIX">DECEPTRIX</a> — Explainable Media-Forensics Platform</h4>
<p>
<i>Deepfake detection &amp; claim verification with admissible evidence · PyTorch · FastAPI · Next.js</i>
</p>
<ul>
<li><b>Five independent forensic signals</b> (ViT visual, lip-sync correlation, 468-point landmark jitter, 2D-DCT spectral analysis, container telemetry) fused by a <b>Bayesian evidentiary engine</b>.</li>
<li>Produces a cryptographically attested <b>5-page forensic dossier</b> with a full SHA-256 chain of custody — "Evidence Before Conclusions."</li>
</ul>
